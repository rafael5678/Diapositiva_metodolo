09 / FLUJO DE DESARROLLO

Git en contexto.
Una historia, una rama.

Convención ilustrativa para asociar los cambios al ticket. Los comandos se muestran como terminal de ejemplo; no se ejecutan sobre ningún repositorio.

zsh — ecomarket-webdemo
# 1. Actualizar la rama principal
$ git switch main
$ git pull --ff-only

# 2. Crear una rama vinculada al ticket
$ git switch -c feature/ECO-101-catalog

# 3. Guardar cambios con contexto
$ git add .
$ git commit -m "feat(ECO-101): add product catalog"

# 4. Publicar rama y abrir Pull Request
$ git push -u origin feature/ECO-101-catalog
$ # PR: ECO-101 · reviewers · CI checks

Convención de nombres

feature/ECO-101-catalog enlaza la rama al trabajo planificado.

Antes de integrar

Revisión por pares, pruebas automáticas y resolución de conflictos. Protege la rama principal.

Después del merge

Verifica el estado real del despliegue antes de marcar la historia como terminada.
